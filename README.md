# Conch

> Turn source documents into structured, context-aware quizzes instantly.

Conch is a modern web application designed to help students and educators transform study materials—such as PDFs, lecture slides, and text files—into interactive, high-quality quizzes powered by AI.

## ✨ Key Features

- **📄 Document Processing**: Upload PDFs, presentation slides, or raw text documents as source material.
- **🤖 Context-Aware AI Generation**: Powered by **Gemini 3.5 Flash-Lite** to extract relevant concepts and output formatted questions directly grounded in your content.
- **🛠️ Interactive Quiz Editor**: Review and adjust difficulty settings, question types (multiple choice, true/false, fill-in), options, and answers.
- **🔗 Seamless Sharing**: Share created quizzes with peers via direct web links.
- **📤 Versatile Study Exports**: Export quizzes to standard formats for offline reviewing or offline test taking.
- **🎨 Custom OKLCH Theme**: Styled with a dynamic light/dark mode interface built using Tailwind CSS v4 and standard OKLCH color palettes.
